Hello! Welcome to the EPQ Website of Nyomi Myles! This is a short, very small project to make a website that will engage students, and allow for more students to learn the A-Level Computer Science course. The primary objective is to be accessible and engaging. Here are some features you can try out immediately: Text-to-Speech (click on this sentence. you can do this for any line of text on this website. even on buttons!) Speech-to-Text (click the button, allow microphone use, and say whatever you want)

Have fun and explore!
